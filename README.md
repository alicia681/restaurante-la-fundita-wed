# La Fondita Gem

# PROMPT MAESTRO — RESTAURANTE LA FONDITA

## Diseño y desarrollo de una web premium para restaurante mexicano en Chicago

Quiero que construyas desde cero una página web profesional, moderna, premium y altamente orientada a conversión para:

**RESTAURANTE LA FONDITA**

Restaurante mexicano de barrio ubicado dentro de **Grand Food**, en Chicago.

La web debe sentirse como una marca gastronómica real, cálida, auténtica y memorable. NO quiero una plantilla genérica de restaurante, ni una web que parezca creada automáticamente por IA.

El objetivo es que una persona que encuentre La Fondita por Google, móvil o redes sociales:

1. Entienda inmediatamente qué es el restaurante.

2. Perciba que la comida es auténtica, casera y apetecible.

3. Sepa exactamente dónde está.

4. Entienda que está dentro de Grand Food.

5. Pueda llamar fácilmente.

6. Pueda obtener indicaciones.

7. Pueda consultar el menú.

8. Confíe en el restaurante gracias a las reseñas.

9. Tenga una experiencia visual memorable.

10. Quiera visitar el restaurante.
